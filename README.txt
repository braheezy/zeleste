IMPORTANT NOTE: Madeline is bald on most sprites because her hair are generated in real-time by the game.

The `raw` folder contains all raw Madeline sprites with the original filenames from the game's meta files.
The `animations` folder contains all animations with their original names from the game's animation XML files, divided as individual frames and as a GIF file.

Generated grass sway previews are written under `assets/generated/foreground/`.

Do note, the animations are made out of the raw sprites, but not all raw sprites are used in animations.

Credits to EXOK if these sprites are used.
